# Personal CV Website

A clean, modern, and minimalist personal CV website designed for college students to showcase their education, skills, and contact information without the need for complex frameworks.

## 🚀 Live Demo
[Link to Live Site](https://yourusername.github.io/repo-name)

## 📖 About The Project

This project is a single-page static website built to serve as a digital curriculum vitae (CV). It is designed to replace traditional PDF resumes with a responsive, interactive web experience.

**What this website does:**
* **Showcases Profile:** Displays a professional hero section, about me, education history, and skills.
* **Provides Contact Info:** Offers a clear, accessible way for recruiters or peers to contact the student.
* **Responsive Design:** Adapts seamlessly to mobile phones, tablets, and desktop screens.

**Key Features:**
* **Minimalist Aesthetic:** Focuses on clarity and readability with a soft, modern color palette.
* **Smooth Navigation:** Features a sticky navigation bar with smooth scrolling between sections.
* **Mobile-First:** Includes a fully functional hamburger menu for smaller screens.
* **Interactive Elements:** Subtle fade-in animations on scroll and hover effects for better user engagement.
* **Easy to Edit:** Structured code with clear comments for customization.

## 🛠️ Built With

* **HTML5:** For the semantic structure of the website.
* **CSS3:** For styling, Flexbox/Grid layouts, animations, and responsive media queries.
* **JavaScript:** For the mobile hamburger menu toggle and scroll-triggered fade animations.
* **Google Fonts:** Using 'Poppins' for modern typography.
* **FontAwesome:** For social and contact icons.

## 📂 Project Structure

The project consists of a single file for simplicity and ease of deployment:

* `index.html`: Contains all HTML structure, internal CSS styles, and JavaScript logic in one place.
